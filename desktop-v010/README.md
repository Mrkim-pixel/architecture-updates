# Windows 건축설계 모듈 업데이트

기존 Android 릴리스와 분리한 Windows 0.1.0 호스트 전용 배포 경로입니다.

- 도면 프로그램, 자재관리, 견적서, 자재산출을 독립 패키지로 배포합니다.
- stable.json은 RSA-SHA256 서명된 메타데이터입니다. 각 ZIP은 SHA-256으로 검증합니다.
- 다운로드 후 다음 프로그램 실행 때 적용하며, 파일 교체 실패 시 이전 프로그램 파일로 복원합니다.
- 첫 도면 패키지는 연결 화면만 업데이트합니다. 기존 BIMCraft 엔진(MIT/Apache-2.0)은 유지합니다. 견적서 기능은 아직 준비 중입니다.
- 사용자 자재·단가·현장·도면, 인증 정보 및 서명 개인키는 포함하지 않습니다.
- 게시자는 모듈별 버전 번호를 증가시키고 호환되는 파일만 서명하여 배포해야 합니다.
