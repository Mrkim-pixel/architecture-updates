# 건축설계 MrKim 업데이트

안드로이드 앱 배포 전용 저장소입니다.

최신 APK는 [Releases](https://github.com/Mrkim-pixel/architecture-updates/releases/latest)에서 다운로드하세요.

기존 앱을 삭제하지 않고 같은 서명의 새 APK를 설치하면 기기에 저장한 현장 데이터를 유지할 수 있습니다. 설치 전 중요한 현장 데이터는 별도로 보관해주세요.

현장 데이터 및 앱 서명 키는 이 저장소에 업로드하지 않습니다.

업데이트 기능이 포함된 앱을 최초 한 번 직접 설치한 후에는 앱 실행 시 새 버전 확인을 지원합니다. APK 설치 자체는 사용자가 승인해야 합니다.
